# ✦ TextFix AI

> An intelligent NLP-powered writing assistant for detecting
> spelling and grammar issues and improving writing quality.

## 🚀 Features

- ✍️ Spelling error detection
- 📝 Grammar checking
- 💡 Suggested corrections
- 📄 PDF text extraction
- 📊 PPTX text extraction
- 📈 Writing analytics
- ⭐ Writing quality score
- 📋 Copy corrected text
- ⚡ Interactive error correction
- 📱 Responsive web interface

## 🧠 How It Works

User Input
↓
Text Extraction
↓
NLP Analysis
↓
Spelling & Grammar Detection
↓
Correction Suggestions
↓
Writing Quality Analysis
↓
Interactive Results

## ⚙️ Installation

### Clone the repository

git clone YOUR_REPOSITORY_URL

cd textfix-ai

### Create virtual environment

python -m venv venv

### Activate it

Windows:

venv\Scripts\activate

### Install dependencies

pip install -r requirements.txt

### Run the application

python app.py

Open:

http://127.0.0.1:5000
